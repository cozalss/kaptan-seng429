# Karar geçmişi

## Tur 1 → Mutabık (e-Fatura)
Klişelerden kaçınan, Türkiye'ye özgü, düşük riskli bir kurumsal iş akışı. Yedekte.

## Tur 2 → Kurul (haberle işlem yapan ajan masası)
Kullanıcının asıl hedefi: yapay zeka ajanlarının haberlere göre (kendi parasıyla) işlem yapması. Araştırma: LLM'in serbest karar vermesi al-tut'u geçemiyor; ortak para havuzu yasal risk.

## Tur 3 → **KAPtan (nihai)**
Fikir turnuvası (9 varyant, ağırlıklı puan):

| Varyant | Puan |
|---|---|
| Kurul (mevcut) | 5,10 |
| KAP bildirim olay masası | 7,95 |
| LLM sınıflandırıcı + kurallar | 6,85 |
| Portföy risk yardımcısı | 6,95 |
| BIST + kripto masası | 5,05 |
| Kendi kendini denetleyen uyum masası | 7,40 |
| AI quant ekibi | 5,50 |
| Söylenti doğrulayıcı | 7,60 |
| **Hibrit: KAPtan** | **8,20** |

Neden KAPtan:
1. GitHub'da BIST + KAP + karar/uyum/onay zinciri yok (Kurul klon gibi görünürdü).
2. Kanıt: LLM sınıflandırıcı + kurallar; BIST'te geri alım işlemleri ve içeriden alımlarda belgelenmiş sapma.
3. Ders saatinde BIST açık → canlı KAP demosu.
4. Kişisel kullanım: emir fişi + manuel giriş (Algolab kapalı; strateji hız istemiyor).
